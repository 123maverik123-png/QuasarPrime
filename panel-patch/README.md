# Патч карточки YouTube для веб-панели

Это два изменённых файла из `static/` сторонней панели
[«Веб-панель для Яндекс Станции»](https://github.com/dimap/yandex-station-web) версии
**0.1.6** (MIT, © 2026 dimap; текст лицензии — в `LICENSE` рядом). Больше ничего в
панели не менялось: остальные файлы, `server.py` и настройки остаются штатными.

## Что даёт

Карточка «Сейчас играет на YouTube» перестаёт быть встроенным плеером и становится
пультом станции:

* **превью трека** (обложка YouTube) вместо iframe — видео в браузере не играет;
* **перемотка**: полоса под треком перематывает **на самой колонке** (мост пересобирает
  поток с нужной секунды, `POST /api/seek`);
* **очередь** и **история** — отдельные окошки в карточке, живут в `localStorage` браузера;
  когда трек доигрывает, очередь переходит к следующему;
* **пауза работает на колонке**: кнопка паузы останавливает станцию (а не только таймер),
  а пауза кольцом на станции останавливает таймер в панели — бейдж показывает
  «пауза на колонке»;
* убраны «Включить здесь», встроенный плеер и ползунок громкости браузера.

Всё это работает только вместе с мостом `quasard-youtube` **0.1.1+** из этого релиза:
панель ходит в него через `/api/yt-bridge`.

## Установка

1. Скопируйте файлы с заменой в папку панели `yandex-station-web-0.1.6`:

   ```
   panel-patch\static\index.html     ->  <панель>\static\index.html
   panel-patch\static\yt-player.js   ->  <панель>\static\yt-player.js
   ```

2. Мост должен быть запущен (`launcher.py` поднимает его сам) и доступен панели как
   `http://127.0.0.1:8099`.

3. Обновите страницу панели с Ctrl+F5 (service worker панели отдаёт файлы из сети, но
   старый JS мог остаться в кэше вкладки).

Проверка: откройте карточку YouTube — вместо плеера будет обложка, под ней полоса
перемотки, ниже «Очередь» и «История». Если карточка пишет «Мост YouTube не отвечает» —
не запущен `quasard-youtube`.

## Откат

Верните штатные `static/index.html` и `static/yt-player.js` из архива панели 0.1.6 —
мост продолжит работать, просто без карточки-пульта.

## Совместимость

Патч сделан под `yandex-station-web 0.1.6`. В другой версии разметка карточки
(`#yt-card`, `#yt-seek`, `#yt-queue`, …) может отличаться — тогда файлы нужно
переносить вручную.
